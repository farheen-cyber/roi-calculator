## Key Insights

1. **India has the highest baseline** (72h) due to SH-6 register + dual accounting standards (Ind AS 102/15)
2. **US is second** (68h) due to ASC 718/820 complexity + Rule 701 annual analysis
3. **Singapore/UK tied** (54h) with simpler IFRS 2 requirements and no additional statutory registers
4. **Common to all**: Cap table, transaction ledger, grant summaries, exercise/vesting reports
5. **Unique to each**:
   - India: SH-6 register (16h/yr)
   - US: Rule 701 analysis (6h/yr)
   - Singapore/UK: Fewer regulatory requirements

## How This Should Drive Compliance Hours Calculation

**Current approach** (WRONG):
- Uses generic complexity factors (0.03-0.15) per shareholder/option holder
- Applies arbitrary accounting baselines (40h India, 38h US, etc.)
- Does not account for actual statutory reports required

**Should be** (CORRECT):
- Start with these baseline hours (72/68/54/54)
- Scale based on company complexity (shareholders, option holders, stage)
- Scale based on which reports apply (e.g., SH-6 only if you have ESOP)
- Scale based on number of transactions (more grants = more transaction-level ledger work)
